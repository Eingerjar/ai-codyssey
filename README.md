# 컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기

## 프로젝트 개요

Python 기초 학습 내용을 복습하고, 배운 내용을 직접 코드로 구현해 보기 위해 제작한 콘솔 기반 퀴즈 게임이다.

사용자는 메뉴를 통해 저장된 퀴즈를 풀거나 퀴즈 목록과 최고 점수를 확인할 수 있으며, 퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장된다.

Python의 기본 자료형과 함수부터 클래스, 메서드, `self`, `__init__`, `method` 등 Python 기초 학습 과정에서 배운 주요 개념을 퀴즈로 구성하였다.

본 프로젝트를 통해 Python 문법과 객체지향 프로그래밍의 기본 개념을 복습하고, 클래스 설계, 예외 처리, 파일 입출력, JSON 데이터 처리 등 실제 프로그램을 구성하는 데 필요한 기초적인 프로그래밍 경험을 쌓는 것을 목표로 한다.

## 퀴즈 주제 선정 이유

Python 기초 학습 과정에서 배운 내용을 복습하고, 주요 개념을 제대로 이해하고 있는지 확인하기 위해 Python 기초와 클래스·객체를 퀴즈 주제로 선정하였다. 변수와 자료형, 함수, 클래스, 메서드, self, **init**, @staticmethod 등 실제 코드 작성에 자주 사용되는 개념을 문제로 구성하여 학습 내용을 자연스럽게 복습할 수 있도록 하였다.

### Quiz와 QuizGame의 역할

Quiz는 “한 문제 하나를 표현하는 객체”이고, QuizGame은 “여러 문제를 관리하고 게임 흐름을 운영하는 관리자”다.
즉, Quiz는 문제 자체의 데이터와 정답 검증을 담당하고, QuizGame은 퀴즈 추가, 문제 풀이, 점수 계산, 저장/불러오기 같은 전체 게임 로직을 담당한다.

### JSON 저장의 장점

- 가독성:

  사람이 직접 읽기 쉬운 텍스트 형식이라, 저장된 퀴즈 내용을 한눈에 확인하기 좋습니다.

- 경량성:

  XML보다 훨씬 간단하고 가볍고, 파이썬의 dict/list 구조와 자연스럽게 매핑됩니다.

- 호환성:

  Python, JavaScript, 웹, 서버 통신 등 대부분 환경에서 쉽게 읽고 쓰기 좋습니다.

### 대량 확장 시 고려할 점

- 전체 파일 로딩의 한계

  현재 구조는 저장 시 전체 퀴즈 목록을 한 번에 JSON으로 다시 쓰고, 불러올 때도 전체를 메모리에 다 읽어오는 방식.
  - 퀴즈가 많아질수록 파일 크기 증가
  - 매번 전체 데이터를 다시 serialize/deserialize 하므로 처리 시간이 증가
  - 메모리 사용량도 함께 증가
  - 특히 자주 저장하거나 대용량 문자열이 많아지면 부담이 커짐

- 동기 I/O로 인한 응답 지연

  save_state()처럼 파일에 바로 쓰는 방식은 동기적으로 동작하므로, 저장이 끝날 때까지 다른 동작이 멈출 수 있음.
  - 사용자 입력이 많아질수록 느려짐
  - 게임 중 저장이 반복되면 체감 성능 저하
  - 파일이 크면 저장 시간도 비례해서 증가

- 개선 방법
  1. 스트리밍 I/O

     대량 데이터가 예상되면 전체 파일을 매번 다시 쓰는 대신 다음 방식을 고려할 수 있습니다.
  - 스트리밍 방식으로 한 번에 한 항목씩 쓰기
  - 임시 파일에 먼저 저장 후 안전하게 교체
  - 일정 간격마다 자동 저장
  - 메모리에 전체 상태를 유지하지 않고 필요한 부분만 로드
  2. DB 전환
     퀴즈 수가 많아지고, 검색/정렬/통계 기능이 늘어나면 JSON 파일은 한계가 생김.

### 정기 백업 또는 자동 백업 파일 생성 절차

- 저장 직후 백업 파일 생성
- backup/ 폴더에 timestamp 기반 파일 보관
- 파일 손상 시 기본 퀴즈 복구 전에 최신 백업 파일 우선 복원
