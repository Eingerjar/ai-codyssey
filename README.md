## 퀴즈 주제 선정 이유

Python 기초 학습 과정에서 배운 내용을 복습하고, 주요 개념을 제대로 이해하고 있는지 확인하기 위해 Python 기초와 클래스·객체를 퀴즈 주제로 선정하였다. 변수와 자료형, 함수, 클래스, 메서드, self, **init**, @staticmethod 등 실제 코드 작성에 자주 사용되는 개념을 문제로 구성하여 학습 내용을 자연스럽게 복습할 수 있도록 하였다.

### 2. 메뉴 기능

- [x] 프로그램 실행 시 메뉴가 출력되어야 한다.
- [x] 사용자가 기능을 선택할 수 있어야 한다.

### 3. 공통 입력/예외 처리 기준 (최소 요구)

- [x] 숫자 입력이 필요한 곳에서 다음 최소 케이스를 처리해야 한다.
- 입력 앞뒤 공백 제거 후 처리한다. (예: `1`)
- 숫자 변환 실패(예: `abc`) 시 안내 메시지 출력 후 재입력 흐름으로 복귀한다.
- 허용 범위 밖 숫자(예: 메뉴 9, 정답 0) 입력 시 안내 메시지 출력 후 재입력 흐름으로 복귀한다.
- 빈 입력(그냥 Enter)인 경우 안내 메시지 출력 후 재입력 흐름으로 복귀한다.
- [x] 프로그램 실행 중 `Ctrl+C`(KeyboardInterrupt) 또는 입력 스트림 종료(EOFError)가 발생해도 “비정상 종료”하지 않도록 처리한다.
- 안내 메시지를 출력하고, 가능한 범위에서 저장 후 안전하게 종료한다.
- [x] 데이터 파일이 없거나 손상된 경우에도 프로그램이 실행 가능해야 한다.
- 파일이 없으면 기본 퀴즈 데이터를 사용한다.
- 파일이 손상되었으면 안내 메시지를 출력하고, 기본 퀴즈 데이터로 복구(또는 초기화)한다.

### 4. Quiz 클래스

- [x] 개별 퀴즈를 표현하는 Quiz 클래스를 정의한다.
- [x] 속성: 문제(question), 선택지(choices), 정답(answer)

- 선택지는 4개를 기본으로 한다.
- 정답은 1~4 중 하나의 번호로 관리하는 방식을 권장한다. (구현에서 일관성 유지)
- [x] 메서드: 퀴즈 출력, 정답 확인 등 필요한 기능을 구현한다.
- [x] Git: Quiz 클래스 작성 후 커밋한다.
